### ❤️ 3. Heart Disease Classification - XGBoost

Aplikasi klasifikasi penyakit jantung menggunakan algoritma **XGBoost dengan optimasi hyperparameter** untuk membantu mengklasifikasikan status penyakit jantung berdasarkan data kesehatan.

Project ini dikembangkan sebagai bagian dari penelitian tugas akhir dengan pendekatan machine learning dan antarmuka aplikasi berbasis web.

**Fitur Utama:**
- 📊 Eksplorasi dan visualisasi dataset.
- ⚙️ Preprocessing data.
- 🤖 Pelatihan model XGBoost.
- 🔍 Optimasi hyperparameter menggunakan GridSearchCV.
- 📈 Evaluasi model menggunakan metrik klasifikasi.
- 🧠 Analisis feature importance.
- 🖥️ Antarmuka aplikasi menggunakan Streamlit.

**Teknologi:** `Python` `XGBoost` `Scikit-learn` `Pandas` `Streamlit`
